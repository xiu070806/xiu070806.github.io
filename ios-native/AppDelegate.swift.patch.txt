Add the following imports and calls to the NEW Capacitor AppDelegate.swift generated by `npx cap add ios`.

1) Add:
import WebKit
import CoreLocation

2) In application(_:didFinishLaunchingWithOptions:), after Capacitor initialization, call:
if let bridge = self.bridge {
    TaximetLocationBridge.shared.attach(webView: bridge.webView)
}

3) In applicationDidEnterBackground:
TaximetLocationBridge.shared.start()

4) In applicationWillEnterForeground:
TaximetLocationBridge.shared.start()

5) In applicationWillTerminate:
TaximetLocationBridge.shared.stop()

The workflow script applies these changes automatically.
